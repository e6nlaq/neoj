# プロジェクトを設定する

`neoj` はグローバルファイルとプロジェクトファイルからTOMLを読み、結合します。

| 範囲         | パス                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| グローバル   | `~/.neoj.toml`                                                                 |
| プロジェクト | 現在のディレクトリまたは最も近い祖先にある `neoj.toml`(リポジトリのルートまで) |

プロジェクトの値がグローバルの値に優ります。`src` と `[template]` はプロジェクト専用で、グローバルファイルに設定するとエラーになります。

## ログイン時のブラウザを制御する

```toml
[login]
open_browser = true
```

yukicoderのCLIトークンのデバイスフローを制御します。`true`(既定)のとき、`neoj` は検証ページをブラウザで開きます。URLとコードはどちらの場合も表示されるため、ヘッドレス環境やSSHセッションでは `false` にします。

## テストのフォルダ名やファイル名を変える

```toml
[testcase]
folder = "test"
filename = "sample-{}"

[handmade]
filename = "handmade-{}"
```

- `folder` はプロジェクト内の相対パスであること、シンボリックリンクを通らないこと、`.git` と `.neoj` を指さないことが必要です。`src` と重なってもいけません(どちらかのディレクトリがもう一方を含む形も禁止です)。
- `filename` は、`{}` をちょうど1つ含む単純なファイル名であることが必要です。`{}` は1始まりのサンプル番号に置き換わります。
- `handmade.filename` は `neoj handmade` が作るケースの名前です。同じ `folder` と同じ `{}` の規則を使い、空いている次の番号を取ります。
- `generate.filename` は `neoj generate` が作るケースの名前で、規則は同じです。[ランダムテストケースを生成する](generate-random-tests.md)を参照してください。

相対パスのフォルダは、最も近いプロジェクトの `neoj.toml` があるディレクトリから解決されます。ダウンロードは、確認なしにフォルダを置き換えます。

## ダウンロード後にサンプルを表示する

```toml
[download]
show_sample = true
```

`neoj` はファイルの書き込みが成功したあと、各サンプルの入力と出力を表示します。

## 問題の切り替え時に作業を退避する

```toml
[stash]
auto_stash = true
auto_apply = true
force = true
```

`auto_stash` は、ダウンロードが置き換える前に前の問題の `src` とテストケースのディレクトリを保存し、`auto_apply` はダウンロードのあと、ダウンロードした問題の退避を復元します。どちらも、ダウンロードした問題が `.neoj/problem.json` の問題と異なるときにだけ動きます。`stash.force`(既定は `true`)は、`neoj stash save` が既存の退避を置き換えられるかどうかを制御します。[作業を問題ごとに退避・復元する](stash-work.md)を参照してください。

## テンプレートを適用する

```toml
src = "src"

[template]
enable = true
folder = "template"
exclude = ["*.md", ".gitkeep"]
mode = "overlay"
```

`enable = true` のときは、`src` と `template.folder` の両方が必要です。問題が変わるダウンロードのあと、`neoj` はテンプレートを `src` にコピーします。

- `template.exclude` は、コピーしないファイルのグロブの一覧です。パターンは `template.folder` からの相対パスと、エントリ名に一致するため、`*.md` はサブディレクトリの中のMarkdownファイルも除外します。一致したディレクトリは中身ごと飛ばします。

- `mode = "overlay"`(既定)は、両方にあるファイルを置き換え、残りを保ちます。
- `mode = "replace"` は、先に `src` の中身を削除します。

隠しファイルも含まれ、テンプレートの中のシンボリックリンクは拒否されます。2つのディレクトリが重なってはいけません。テンプレートのディレクトリがなければエラーで、空なら許されます。同じ問題をもう一度ダウンロードしてもテンプレートは再適用されないため、`src` の編集が上書きされることはありません。

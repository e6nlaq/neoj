# 作業を問題ごとに退避・復元する

`neoj download` はテストケースのディレクトリを置き換え、テンプレートを適用するため、別の問題へ移るとき、手で編集したテストとコードは失われます。`neoj stash` は問題ごとに作業ファイルのスナップショットを保存するため、作業を失わずに問題を行き来できます。

退避は1つの問題に属し、`.neoj/problem.json` の隣の `.neoj/stash/` に保存されます。別の問題をダウンロードしても削除されません。退避はGitと無関係です。同梱の `.gitignore` は `.neoj/` を除外するため、既定ではコミットされません。

## コマンド

```bash
neoj stash            # same as: neoj stash save
neoj stash save
neoj stash list
neoj stash apply
neoj stash pop
neoj stash drop
neoj stash clear --force
```

| コマンド | 説明                                                      |
| -------- | --------------------------------------------------------- |
| `save`   | 現在の問題の作業ファイルを保存します。                    |
| `list`   | すべての退避を表示します。現在の問題には `*` を付けます。 |
| `apply`  | 現在の問題の退避を復元します。                            |
| `pop`    | 現在の問題の退避を復元し、そのあと削除します。            |
| `drop`   | 現在の問題の退避を削除します。                            |
| `clear`  | すべての退避を削除します。`--force` が必要です。          |

`list` と `clear` 以外のコマンドは、`.neoj/problem.json` に記録された問題に対して動きます。そのため、先に `neoj download <url>` を実行します。問題が記録されていないときや、現在の問題の退避がないときは、`neoj stash` がエラーを報告します。

`save` は同じ問題の既存の退避を置き換えます。これは既定では許され、`stash.force = false` で止められます。`false` にしたあとは、`--force` を渡すまで `save` が失敗します。

## 保存されるもの

スナップショットには次が入ります。

- 設定されていれば `src`。ファイルとサブディレクトリのすべてです。
- `testcase.folder` のディレクトリ。

シンボリックリンクなどの特殊なファイルは、エラーで拒否されます。退避の中では、2つの論理ディレクトリを固定した名前で保存します。

```
.neoj/stash/atcoder/abc300_a/
├── meta.json
├── src/
│   └── main.cpp
└── testcase/
    ├── sample-1.in
    └── sample-1.out
```

`meta.json` は問題URL、プラットフォームとスラッグ、保存した時刻、保存時点で設定されていたフォルダ名を記録します。スラッグは問題URLから決まります(AtCoderなら `abc300_a`、yukicoderの `/problems/no/480` なら `no480`、`/problems/1480` なら `id1480`)。そのため、ディレクトリ名が読み取れます。

## 復元

`apply` は、保存時点で記録されたパスではなく、現在の設定にあるディレクトリへ復元します。そのため、`save` と `apply` のあいだで `testcase.folder` の名前を変えても動きます。名前が変わったときは `neoj` が警告します。`src` が設定されなくなっていても退避がそれを含むときは、その部分を警告とともに飛ばします。

復元は正確です。退避にあるファイルは書き込まれ、ローカルには存在するが退避にないファイルは削除されます。コマンドは書き込んだファイル数と削除したファイル数を報告します。退避そのものは、`pop`、`drop`、`clear` を実行するまで残ります。

## 自動化する

```toml
[stash]
auto_stash = true
auto_apply = true
force = true
```

両方のオプションを有効にすると、`neoj download` は次のように動きます。

1. 問題を取得します。
2. `.neoj/problem.json` の問題と異なるときは、その前の問題の作業ファイルを保存します。
3. テストケースのディレクトリを置き換え、問題が変わっていればテンプレートを適用します。
4. 新しい問題の退避があれば復元します。

どちらのオプションも問題が変わったときにだけ動くため、同じ問題の再ダウンロードが、新しいサンプルを古いスナップショットで置き換えることはありません。取得が失敗したときは、作業ファイルと退避のどちらもそのまま残ります。

# Install neoj

`neoj` is published on npm as `neo-oj`. Install it globally with Bun or npm.

## With Bun (recommended)

```bash
bun install -g neo-oj
```

## With npm

```bash
npm install -g neo-oj
```

## Requirements

`neoj` requires [Bun](https://bun.com) 1.4 or newer at runtime. Install Bun if it
is not already available.

Verify that the CLI is on your `PATH`:

```bash
neoj --help
```
